# hello-demo

The smallest possible demo-studio run: a self-contained fixture app (no dev
server, no login) recorded with `film-demo`, used to sanity-check a fresh
checkout and to generate the preview video in the root `README.md`.

## Show

1. Open `app/index.html`, wait for it to settle.
2. Focus the task input.
3. Type "Ship the v1 release".
4. Click Add — expect the new item to appear in the list.
5. Wide — let the viewer see the list update.
6. Focus the new list item, hold ~2s (the payoff).
7. Wide, hold 2.5s, stop.

Silent — no narration track for this example (see the root README for how to
add one with `narrate` + `sync-narration`).
