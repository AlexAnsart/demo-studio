# Create a task

## Say
1. "Here's the task board."
2. "Type what you need, hit add, and it appears instantly."
3. "No reload — the list updates in place."

## Show
1. Preload app off-camera; first filmed beat = wide establish.
2. Wide — viewer sees the full board.
3. Focus the task input.
4. Type "Ship the v1 release".
5. Click Add — expect the new row (never stay zoomed on the input after submit).
6. Wide — list update must be visible.
7. Focus the new row, hold ~3s (payoff).
8. Wide, hold ~2.5s, stop.

## Prep
- No login required for the hello fixture; real apps: set `auth.loginRequired` and use `buildDemoSession` off-camera.
- Compose (narrated): `idleGapMin=9999,toolWaitMax=2.5,preToolWaitMax=2,tailHold=4`
