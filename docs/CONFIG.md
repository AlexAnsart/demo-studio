# `demo.config.json` reference

Generated by the `demo-setup` skill; every field has a safe default (see
`skills/film-demo/scripts/config.mjs`), so an empty or partial file still
works. Copy `demo.config.example.json` to `demo.config.json` at your project
root to start from a template.

| Field | Default | Notes |
|-------|---------|-------|
| `app.baseUrl` | `http://localhost:5173` | URL your demo scripts navigate to first |
| `app.devCommand` | — | Documentation only — the agent reads this to know how to start your app before recording |
| `app.viewport` | `1920x1080` | Recording resolution. Keep `frame.canvasWidth/Height` in sync if you change it |
| `auth.loginRequired` | `false` | If `true`, `demo-setup` scaffolds an off-camera login helper |
| `auth.loginPath` / `*Selector` | — | CSS selectors for the login form, used by scaffolded `run.mjs` |
| `auth.credentialsEnv` | — | **Names** of the env vars holding the demo account's email/password — never the values themselves |
| `cursor.scale` | `1.6` | Pointer size multiplier |
| `cursor.color` | `#0A0A0A` | Pointer fill color (hex) |
| `camera.padding` | `0.22` | Breathing room around a `focus()` zone, as a fraction of its size |
| `camera.maxZoom` | `1.7` | Hard cap — higher visibly softens a 1920x1080 source |
| `camera.transitionSec` | `0.72` | Default pan/zoom transition length when a shot has no cursor-derived timing |
| `speedup.toolWaitMax` | `4` | Seconds a tool/API spinner is compressed to |
| `speedup.preToolWaitMax` | `2.5` | Seconds of pre-tool latency kept |
| `speedup.idleGapMax` / `idleGapMin` | `1.8` / `3.5` | Any inactive gap longer than `idleGapMin` is compressed to `idleGapMax`. Set `idleGapMin` very high (e.g. `9999`) for narrated videos to protect narration-driven holds |
| `frame.preset` | `studio-dark` | One of `studio-dark`, `clean-light`, `none` (`skills/film-demo/scripts/presets.mjs`) |
| `frame.canvasWidth` / `canvasHeight` | `1920` / `1080` | Final output resolution |
| `narration.provider` | `none` | `none` (silent pipeline, no API key) or `elevenlabs` |
| `narration.voiceName` / `modelId` / `stability` | `Rachel` / `eleven_v3` / `1.0` | Passed to `narrate`'s `generate_narration.py` |
| `narration.apiKeyEnv` | `ELEVENLABS_API_KEY` | Name of the env var holding the key |
| `captions.enabled` | `true` | Burn captions during `sync-narration` |
| `captions.maxCharsPerLine` | `60` | Soft wrap target (hard cap is 80, enforced by `build-plan-from-align.js`) |
| `output.dir` | `demos` | Where scaffolded demo folders and final videos live |

## Presets

`studio-dark` (default), `clean-light`, `none` — see
`skills/film-demo/scripts/presets.mjs` for the exact values, or add your own
preset there directly.
